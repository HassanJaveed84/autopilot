The British Library's address is 96 Euston Road, London, NW1 2DB, England [1].

Many independent listings give this same address, including Art Fund, Time Out and Britain Express. It's the St Pancras site. It is on the north side of Euston Road, between Euston railway station and St Pancras railway station. [2]

The library also has a branch in Boston Spa, West Yorkshire. That isn't the London site, so don't use it for a London visit.

The address itself is stable. If you're going in person, check the library's website for opening hours and any closures first. One page I found mentioned planned maintenance closures earlier in 2026.
